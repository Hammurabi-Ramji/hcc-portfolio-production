## 🛠️ SCRIVENER 3 SETUP INSTRUCTIONS

### STEP 1: Project Creation
1. Open Scrivener 3
2. Create New Project → "Blank Project"
3. Name: "FDA_Compliance_Dossier_[Year]"
4. Save Location: Dedicated FDA compliance folder

### STEP 2: Binder Structure Implementation
```
File → Import → Multiple Files
Select and import the organized folder structure
Drag and arrange according to the hierarchy above
```

### STEP 3: Document Templates Setup
1. Go to Project → Project Templates
2. Create document templates for each form type
3. Set up auto-numbering for controlled documents
4. Configure metadata fields for tracking

### STEP 4: Custom Metadata Fields
**Project → Meta-Data Settings → Add Custom Fields:**
- Document Type (SOP, Form, Record, Report)
- Effective Date
- Review Date
- Document Number
- Revision Level
- Approval Status
- Owner/Responsible Person
- CFR Reference

### STEP 5: Collections Setup
**View → Collections → Add Collection:**
- "Current Action Items"
- "Pending Reviews" 
- "FDA Critical Documents"
- "Training Materials"
- "CAPA Items"

## ⚙️ AUTOMATION FEATURES

### Scrivener 3 Auto-Features Setup:

1. **Auto-Numbering Documents**
   - Format → Options → Auto-Number → Enable
   - Pattern: SOP-<$n:0000>

2. **Automatic Compilation**
   - File → Compile → Custom Format
   - Include Table of Contents
   - Headers/Footers with document control info

3. **Backup Automation**
   - Scrivener → Preferences → Backup
   - Auto-backup every 5 saves
   - Keep 25 backup files

4. **Document Linking**
   - Use Edit → Insert → Cross-Reference
   - Link related documents (SOPs to forms, etc.)
