# SUE Visual Asset Pack

This pack contains production-ready extension icons, scalable SVG marks, branded button assets, and the logo banner used by the SUE sidebar UI. The visual system uses a midnight AI-console foundation with blue, violet, and cyan accents for a polished browser-native product feel.

| Asset | Purpose |
|---|---|
| `icon16.png`, `icon32.png`, `icon48.png`, `icon128.png` | Chrome extension manifest and toolbar icons |
| `icon*.svg` | Scalable icon source files for UI and documentation |
| `sue-logo-banner.png` | README, store listing, and launch branding banner |
| `button-*.svg` | Branded CTA and quick-action visual references |
| `asset-manifest.json` | Palette and asset inventory |
