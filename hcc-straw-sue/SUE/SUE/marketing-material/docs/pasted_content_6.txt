## I. GLOBAL SHELL COMPONENTS

### 1.1 Sidebar Container
```
├─ ResizablePanel (min: 320px, max: 600px, default: 400px)

```

### 1.3 System Status Bar
```
├─ ConnectionIndicator (WebSocket state: connected/syncing/offline)
├─ ModelStatus (current LLM: GPT-4/Claude/Llama, with toggle)

```

## V. TECH STACK SPECIFICATION

```
Frontend: React 18 + TypeScript + Tailwind CSS
State: Zustand (lightweight) or Redux Toolkit (complex)
UI Components: Radix UI (headless) + custom styling
Animation: Framer Motion (smooth, physics-based)
Editor: BlockNote (Notion-like) or TipTap (ProseMirror)
AI Streaming: Vercel AI SDK or custom EventSource
Storage: 
  - Local: IndexedDB (Dexie.js) or SQLite (via sql.js)
  - Sync: Supabase or self-hosted Postgres
Browser API: Chrome Extension Manifest V3
  - content_scripts (page interaction)
  - background (service worker)
  - side_panel (the sidebar itself)
Build: Vite (fast HMR, optimized bundles)
```

---

## VI. KEY INTERACTION PATTERNS

1. **Contextual Awareness:** Every tab knows what page you're on and adapts
2. **Progressive Disclosure:** Complex features hidden behind "Advanced" toggles
3. **Keyboard First:** Every action has a hotkey, shown in tooltips
4. **AI as Co-pilot:** Not replacement but augmentation (human always in control)
5. **Data Sovereignty:** Local-first, sync optional, export always available
