SLIDE 8: DOCUMENTATION PRINCIPLES
=================================
DOCUMENTATION PRINCIPLES

📝 ALCOA-C REQUIREMENTS:
A - Attributable (who did it?)
L - Legible (can others read it?)
C - Contemporaneous (done at time of activity)
O - Original (first recording)
A - Accurate (correct and complete)
C - Complete (all required information)

✅ DOCUMENTATION RULES:
• Write in permanent ink
• No white-out or correction fluid
• Single line through errors
• Initial and date all corrections
• Complete all fields
• Sign and date all entries

SLIDE 12: MASTER PRODUCTION RECORDS
===================================
MASTER PRODUCTION RECORDS

❓ WHAT IS AN MPR?
• Master document defining the manufacturing process
• Contains all instructions for production
• Includes in-process controls and testing
• Specifies equipment and materials

✅ MPR REQUIREMENTS:
• Only approved versions used
• No unauthorized changes
• All steps must be followed
• Complete documentation required
• Supervisor review and approval

❌ NEVER:
• Skip steps "because you know better"
• Make undocumented changes
• Use outdated versions
• Leave sections blank
