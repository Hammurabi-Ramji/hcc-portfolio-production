### **QUICK REFERENCE CARD - DOCUMENTATION**

```
DOCUMENTATION QUICK REFERENCE

ALCOA-C PRINCIPLES:
A - Attributable (who?)
L - Legible (readable?)
C - Contemporaneous (when?)
O - Original (first record?)
A - Accurate (correct?)
C - Complete (all info?)

DO:
✓ Write in permanent ink
✓ Document in real-time
✓ Complete all fields
✓ Sign and date entries
✓ Report deviations immediately

DON'T:
✗ Use white-out or correction fluid
✗ Leave blank spaces
✗ Backdate entries
✗ Make unauthorized changes
✗ Copy from other records

CORRECTIONS:
• Single line through error
• Initial and date correction
• Make change legible
• Use same ink color
• No erasures or overwriting
```
