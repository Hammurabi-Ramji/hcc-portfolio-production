## Observed lifecycle

1. **Register** `POST /api/auth/register` → 201 `{user}` + HttpOnly `SameSite=Strict` `straw_session`
2. **Me** `GET /api/auth/me` → 200 identity with cookie
3. **Reload** `page.reload()` retains cookie; `/me` restores the same email
4. **Refresh** `POST /api/auth/refresh-token` → 200, rotates cookie; prior cookie → `/me` 401
5. **Logout** `POST /api/auth/logout` → `data:null`, cookie cleared; reload keeps `/me` 401
6. **Login** `POST /api/auth/login` → 200; reload → `/me` restores session
7. **Unsupported** `GET/POST /api/auth/verify-email`, `POST /api/auth/forgot-password`, `POST /api/auth/reset-password` → **501 `UNSUPPORTED`** (no email transport; unchanged contract)

Nine named passes recorded in `browser-lifecycle-results.json`.
