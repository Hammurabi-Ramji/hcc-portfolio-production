## About

The Radix Labs Regulatory Documentation System is a comprehensive desktop application designed specifically for pharmaceutical manufacturing companies to manage regulatory documentation, ensure compliance with industry standards, and maintain audit trails.

### Key Features

- ✅ **21 CFR Part 11 Compliance** - Electronic records and signatures
- ✅ **Health Canada GMP** - Good manufacturing practices
- ✅ **VICH Guidelines** - International harmonization standards
- ✅ **Electronic Signatures** - Digital signature capabilities
- ✅ **Audit Trail** - Complete activity monitoring and logging
- ✅ **Document Management** - Professional document processing
- ✅ **User Management** - Role-based access control
- ✅ **Offline Operation** - PWA capabilities for offline use

## Installation

### Option 1: Windows Installer (Recommended)

1. Download `Radix-Labs-Regulatory-System-1.0.0-installer.exe`
2. Run the installer as administrator
3. Follow the installation wizard
4. Choose installation directory (default recommended)
5. Launch from desktop shortcut

### Option 2: Portable Version

1. Download `Radix-Labs-Regulatory-System-1.0.0-portable.exe`
2. Extract to desired location
3. Run `Radix Labs Regulatory System.exe`

### Silent Installation

```cmd
Radix-Labs-Regulatory-System-1.0.0-installer.exe /S
```

## Troubleshooting

### Common Issues

#### Application Won't Start

- Check Windows Event Viewer for errors
- Verify antivirus exclusions
- Ensure port 3001 is available
- Check system requirements

#### Login Problems

- Reset password through administrator
- Check account status and lockout
- Verify MFA configuration
- Review security logs

#### Performance Issues

- Check system resources
- Clear application cache
- Optimize database
- Update system drivers

### Log Files

Application logs are located in:

```
C:\Program Files\Radix Labs\Regulatory System\logs\
```
