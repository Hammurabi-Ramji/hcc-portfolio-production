## Limits, legacy disposition and downstream ownership

Batch installation is atomic per file with rollback, not a globally atomic directory snapshot or crash journal. Rollback compares expected installed bytes before deletion, preserves changed/unreadable/missing destinations and returns exact paths plus retained backup directory if it cannot safely restore. A noncooperating writer can still race the comparison and unlink, and an external process can mutate output during a save. Persistent I/O failures can retain staging/backups; successful cleanup is best effort with a Drop retry. Do not claim global multiwriter transaction isolation, power-loss durability, or Unix execution from these Windows tests. W4 S18 owns observed concurrency rollout.
