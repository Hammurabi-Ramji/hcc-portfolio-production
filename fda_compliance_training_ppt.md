**Slide 8: Documentation Principles**
```
DOCUMENTATION PRINCIPLES

ALCOA-C REQUIREMENTS:
A - Attributable (who did it?)
L - Legible (can others read it?)
C - Contemporaneous (done at time of activity)
O - Original (first recording)
A - Accurate (correct and complete)
C - Complete (all required information)

DOCUMENTATION RULES:
• Write in permanent ink
• No white-out or correction fluid
• Single line through errors
• Initial and date all corrections
• Complete all fields
• Sign and date all entries
```
