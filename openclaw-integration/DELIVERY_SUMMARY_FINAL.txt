💻 HOW TO BUILD THE EXECUTABLE
================================================================================

$ build.bat
Result: dist/openclaw.exe (~45-50 MB)

OPTION 2: Using pkg Directly
$ npm install -g pkg
$ pkg bin/openclaw.js --targets win-x64 --output dist/openclaw.exe

OPTION 3: Using nexe
$ npm install -g nexe
$ nexe bin/openclaw.js -o dist/openclaw.exe -t win-x64
