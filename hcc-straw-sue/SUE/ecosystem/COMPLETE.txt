## QUICK START (5 MINUTES)

1. Prerequisites: Node.js 18+, Docker, pnpm

2. Navigate to ecosystem:
   cd C:\SUE\ecosystem

3. Install dependencies:
   pnpm install

4. Setup environment:
   cp .env.example .env

5. Start Docker services:
   docker-compose up

6. In separate terminals, start each app:
   ├─ cd sue-cloud-backend && pnpm dev    (port 8000)
   ├─ cd sue-dashboard-web && pnpm dev    (port 3000)
   ├─ cd sue-admin-portal && pnpm dev     (port 3001)
   └─ cd sue-ai-chat && pnpm dev          (port 3002)

7. Access applications:
   ├─ Web Dashboard: http://localhost:3000
   ├─ Backend API: http://localhost:8000
   ├─ Admin Portal: http://localhost:3001
   └─ AI Chat: http://localhost:3002

## DEPLOYMENT OPTIONS

Development (Local):
  docker-compose up
  pnpm dev (in each component)

Staging (Docker + Kubernetes):
  docker build -t sue-backend ./sue-cloud-backend
  docker build -t sue-dashboard ./sue-dashboard-web
  kubectl apply -f k8s/staging/

Production (Cloud Kubernetes):
  ./scripts/build-all.sh
  ./scripts/push-all.sh
  kubectl apply -f k8s/production/

Mobile App Store:
  pnpm run build:ios      (iOS App Store)
  pnpm run build:android  (Google Play)
